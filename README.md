📱 App Data Analysis (Google Play Store EDA) — Data Cleaning & Insights with Python

📊 Overview :
This project analyzes a dataset of mobile applications (Google Play Store) to uncover insights about ratings, installs, and user reviews.
Using Python’s powerful data analysis libraries, the notebook demonstrates how to clean, visualize, and interpret real-world app data.

🧠 Objectives

. Identify missing values and handle them properly
. Detect and remove duplicate entries
. Analyze numeric relationships using correlation heatmaps
. Visualize data trends for better understanding
. Prepare the dataset for further machine learning or predictive modeling

🛠️ Tools & Libraries Used
Tool                             Purpose
Python	                         Core programming language
Pandas	                         Data manipulation & cleaning
NumPy	                         Numeric computation
Matplotlib	                     Data visualization
Seaborn	                         Statistical data visualization
Jupyter Notebook / VS Code	     Code execution and documentation

📂 Project Workflow :

1-  Data Import & Inspection
    .Loaded dataset into a Pandas DataFrame
    .Checked shape, data types, and overall structure

2-  Data Cleaning
    .Handled missing values
    .Removed exact duplicate rows
    .Converted text-based columns (like size, installs, price) into numeric formats

3-  Exploratory Data Analysis (EDA)
    .Visualized missing data using heatmaps
    .Calculated correlation between numeric features
    .Displayed bar charts for rating distributions

4-  Result Summary :
    .Found data quality issues and resolved them
    .Identified relationships between user ratings and installs
    .Prepared cleaned dataset for further modeling

📈 Key Insights :

. Apps with higher ratings often have more installs and reviews
. Many apps had missing or inconsistent size and price data
. Correlation analysis revealed that Reviews and Installs are highly related
